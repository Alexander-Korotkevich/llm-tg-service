# LLM Telegram Bot Service

Распределённая система на основе микросервисной архитектуры, предоставляющая доступ к LLM-консультациям через Telegram-бота с безопасной JWT-аутентификацией.

## 🎯 Цель проекта

Демонстрация принципов построения безопасных распределённых приложений с разделением ответственности между сервисами. Система состоит из двух независимых компонентов:

1. **Auth Service** ([Документация](./auth-service/README.md)) — сервис аутентификации и выдачи JWT-токенов
2. **Bot Service** ([Документация](./bot_service/README.md)) — Telegram-бот с интеграцией LLM через OpenRouter
